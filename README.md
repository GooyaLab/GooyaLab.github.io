# Gooya Lab website (Hugo + GitHub Pages)

Edit content in **data/** — no design code needed:

| Page | File |
|---|---|
| Home text, notice box | `data/home.yaml` |
| Director card | `data/director.yaml` |
| News | `data/news.yaml` |
| Team | `data/team.yaml` (photos: `static/images/team/`) |
| Research | `data/research.yaml` (images: `static/images/research/`) |
| Publications | `data/publications.yaml` (thumbnails: `static/images/papers/<id>.jpeg`) |
| Events | `data/events.yaml` (photos: `static/images/events/`) |
| Join Us | `content/join-us.md` |
| Footer partners | `data/partners.yaml` |
| Colours | `static/css/style.css` (top of file) |

Every commit to `main` rebuilds the site automatically.
